# Synthetic inactive region-model examples

These are mathematical inputs for [draft 1](../external-interference.md), not
accepted requests, provider guarantees, canonical-authority registration or host
observations. Providers are the fictional typed integer declarations from the
complete bounded parallel-effects source fixture. Supplementary descriptors do
not change that source's actual `parallel-effects-unproved` result.

`snapshot-a` and `snapshot-b` assume original integer requests 1 and 2. The model
table assumes they name distinct physical keys under one common authority.
`compare` returns `disjoint-in-model`, `executable:false`, with explicit assumptions
and remaining gates. Tests additionally map different namespaces/keys to the same
physical key, reject unsupported aliases and preserve original requests across
revisions/terminal channels/retries. These files are generated by the pure
`proofs.external_interference_examples.bundle` fixture; the test compares exact
bytes. Their pins are integrity checks, not signatures or evidence of consent.
