These synthetic declarations follow the new standalone provider-region profile.
`descriptor.json` binds the unchanged fictional provider from
`../drafts/external-interference-examples/provider-a.json`; its request type is
Integer. Both finite channels use the exact namespace pin; the namespace points
to the included synthetic authority text, whose integrity is not registration or
trust evidence. No request value, event or physical mapping is supplied here.

The Rust SDK tests exercise actual metadata decoding, provider/V1/V2/nominal checks,
both channels, cache/error/budget behavior and unchanged real RP-03 resource bytes.

that is evidence of no selection/admission, not acceptance of new C12 semantics.

actual provider/authority/host evidence remain separate work.
