# Candidate A authoring profile 0.14.0

**Status:** Accepted under [ADR-0064](../decisions/0064-finite-work-authoring.md)
and owner delegation; effective on parent/main integration. Conditional declarations
supply no accepted request/value/storage/current grant or enabled work.

Inherit [source 0.13](profile-v0.13.md) at baseline
`c3ce9d2081735675670cfb48e7a4bd4ef8cd90ae`, except below. Header is
`Choreoform authoring "0.14.0".`, companion version `0.13.0` / profile `0.14.0`.
Use the [closed schema](../../schemas/authoring/bindings-0.13.schema.json) and
[versioned grammar](candidate-a-v0.14.ebnf), whose productions are unchanged.
Existing sentences express capability effects, pure inputs, compensation links,
original request/capture/entry and surviving ownership. No live receipt, unknown
terminal tag or current-authority syntax is introduced. Older profiles remain fixed.

Select exact [core 0.11](../dialects/core-owned-work-v0.11.md),
`sha256:246bf3835eef25f8adf76bce39e6b887715e098761e675f821bf745a8111d29e`,
on existing IR 0.4. Libraries require semantics plus all eleven core artifacts;
CLI embeds only known semantics/core bytes. Every actual provider/source/type /
history descriptor and its applicable profile stays explicitly supplied and checked,
including unused declarations. Package framing names source 0.14; formatting /
reparse/coordinated aliases preserve within-profile identity. Normal roles, metadata
reads, lexical visibility, private original UTF-8 clauses/public spans stay intact.

An intermediate surviving body has one capability activity and its own exact direct
surviving child. Inputs may be supported pure parameterless expressions of the exact
capability type using conditionally available local data with complete reads. Child
request seeds use their own source's accepted input type, possibly different from
the parent's seed. Retain only the readonly original accepted request after empty
pre-entry access, complete source/control/provider/owner provenance, actual capability
recipients and strict invalidation. No unknown/ancestor/source result is seeded.

Non-read-only work uses matched stable-key metadata; all work is one-attempt,
timerless with an explicit matching general source. Commands and every explicit
compensator (including read-only class) require capturing-first entry at the source's
actual-use timerless wait, with local uninitialized exclusively written target.
Compensates names the immediate original source; own class and compensation purpose
are independent. Only uncompensated read-only inquiry retains pre-capture entry.
Broader preterminal/possibly-completed compensation, retries/timers/extra work and
general P4/ownership remain unsupported by this finite proof.

Keep 16,384 tokens / 1,000,000 parser visits, shared 100,000 lowering/dependency
work, depth 64 and 1 MiB transport; old unknown headers/fragments retain old quotas.
All earlier core/source/wire/schema/hash/artifact/report and benchmark bytes stay fixed.

## Native disclosure

All eleven checking/advisory views retain inherited declarations. The six views
including concurrency add optional work only on new-core intermediate
ownedContinuationScopes rows. Its fields identify site, capability, input expression,
effectClass, optional compensates and mandatory hostRequirements, bound to existing
same-revision owner/source/request/closure/child relations. Query means uncompensated
read-only inquiry; it is null for commands/compensators. An actual new-core query may
have both query and work; passive leaves and old-core rows omit work. Preserve
preCaptureEntry, conditional checks/gates and final continuationScopes separate
from ordinary/legacy/old-flat coverage. Requirements are premises, never accepted
host transitions. Reuse immutable proof/shared rows, reserve complete output after
inherited rows and enforce the final whole 1 MiB before stdout. Overflow or revision
mismatch refuses without a partial report or another admission pass.

New work/compensation gets NEW logical effect/key; technical attempts alone retain
identity. Actual supported providers, accepted P6 activation/current grants/open
receiver/cutoff, exact occurrence/request/input/value revisions/digest/effect/key /
attempt, immutable storage/full authenticated provenance, actual correlated source
capture and eligible compensation/business consequential/irreversible conflict
acceptance remain live host gates. Failed acceptance leaves the old owner accountable;
all activated transitive effects/subscriptions/children stay owned until accepted
settlement. Metadata, true predicates or work success enable no operation, settle
no original source, resume no parent and prove no liveness. Parent #46 remains draft,
forty scenarios Partial and G1–G4 conditional. Complete validator/benchmarks/general
near-English/protected accessible visual and actual host/browser/user/independent /
phase evidence remain open. No Phase 2.
