# Inert recorded evidence

[Typed claims0.1.0](recorded-v0.1.md) defines a bounded documentary artifact with
literal originals, exact typed payloads, claimed event/delivery identity, reported
time and asserted partial order. Its [worked vectors](recorded-0.1/README.md) and
[publication/reference evidence](../evaluation/0098-recorded-evidence-contract.md)
are synthetic contract data and existing API checks, not actual incident records
or a new production reader. [ADR-0098](../decisions/0098-recorded-evidence-typed-claims.md)
records the exact accepted publication and remaining implementation/trust gates.

No representation/type/hash result authenticates a source, accepts historic
business decisions, grants current authority, reconstructs hidden content or
replays/dispatches work. Full trusted RP08 reconciliation and the remaining Phase1
process/authoring/validator/user/host evidence are separate obligations.
