accepted contracts/profiles/schemas/artifacts/hashes/report meanings and committed

Read accepted ADR-0008/P1/P3/IR compensation/effect/identity/race/closure rules.
Distinguish a new activity's own effect class from its explicit compensates link:
compensation is new work linked to a confirmed or possibly completed prior effect,
not fictional rollback or a requirement that the compensator itself be compensatable.
Distinguish a new logical effect/key from a technical retry and stable-key metadata
from implemented provider promises. Preserve actual current authority, live conflict
and irreversible-race constraints, cancellation cutoff and all activated transitive
accountability. Do not invent a confirmed fact from unknown, classify declarations
as accepted occurrences or merge P4 history activation with P6 ownership.

Probe actual core-0.10 composed SDK first refusals for independently matched new
irreversible/compensatable provider/effect/general-source/terminal-capture metadata,
each with and without a compensation link, in capturing-first and pre-capture
layouts. Test read-only work with an explicit compensation link independently of
effect class; valid versus nonactivity/wrong-provider/idempotency mismatches must
retain their genuine earlier refusals. Keep original-source effect classes distinct
from new-work classification. Inspect unresolved-source/transitive/source-wait /
terminal-disposal premises rather than claiming new work is enabled by graph entry.

Probe pure constructed inputs of the correct type, identity wrappers and typed
input construction from a local original-source capture (including a child request
of the new input type). Check that normal static type/read/provider relationships
actually pass before reporting the owned exact-input restriction. A pre-capture
constructor may be refused at an earlier shape/input barrier; do not falsely claim
a later availability judgment was executed. Include genuine earlier type/read
refusals and source-level existing syntax/lowering evidence with exact first stages.
Retain original-request seed/access/provenance/recipient/invalidation and all
all-declaration/finite child/ordinary-only fault-entry barriers. Reuse existing
regressions rather than duplicating every accepted proof.

Critique candidate next scopes: explicit finite command/compensation proof and
supported pure local request construction versus a broad effect-class loosening,
new wire fields, preterminal commands and general P4/ownership. Identify whether
existing IR/activity work/compensates/entry/capture/expression relations represent

silently label commands as queries. Preserve old ordinary/legacy/flat and conditional

relations and mandatory new-effect/authority/correlation/conflict/settlement gates.

manufactured complete benchmark or phase closure. Freeze a separate signed plan
before any production permission, input rule or serialized contract change.
