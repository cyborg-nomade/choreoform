and IR 0.2. Work policies name a general provider fault source once using
`Recognise faults from "Source".` Multiple attempts require it and reuse the exact
pin for inner retry binding; their retry sentence names only clock and basis.

inner fields. Older grammars, schemas, contracts and hash domains remain fixed.

actual-use endpoints, semantic provider identity and human/unvisited/unused contexts
remain checked. General-source provider protection contributes complete policy
reads even without a use; the new lowering path walks its metadata once rather
than duplicating general and retry paths. Source spans survive semantic refusals.
No resource kind, visibility exception, quota increase or automatic eligibility is
introduced. Known whole-program and legacy fragment/unknown bounds remain fixed.

static use rows, including unvisited declarations. Unused policies have no use row.

once per exact source pin; eligible retry names remain separate. Output reuses the
SDK report without another admission. Capture/use/catalogue rows share cumulative
budgeting and final combined JSON is bounded at 1 MiB before stdout. Empty new
fields stay omitted, preserving earlier output. Existing capture, retry, historical,
isolated and conditional owned-local views compose with the new disclosures.

capture/owned-local composition; every checking view; formatting/reparse/aliases /
