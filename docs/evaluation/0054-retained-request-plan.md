# Owned immutable request snapshots: frozen dependency plan

**Date:** 2026-11-08<br>
**Baseline:** `54becbad2235e76cd9681a9b59120f261b57f818`, draft #46 after PR #68<br>
**Authority:** ADR-0018; no live request/storage/dispatch/closure authorization

Use a dedicated stacked dependency PR and ADR-0054. Existing fresh-local recovery
can capture a terminal result, but cannot read the original request after owner
disposal. A current ancestor value, ordinary initializer or identifier in history
is not that request. Implement one explicit bounded raw contract before authoring
and effectful continuation. Preserve every prior wire/core/source/artifact and
current RP-01 package. No host event/receipt is generated by this analysis.

Introduce Definition IR 0.4 with required closed scope retainedRequests mapping
local DataIDs to origin activity NodeIDs; the bounded initial core subset admits
at most one mapping per scope. Empty maps on all other scopes. Publish exact
core 0.8 with all seven inherited bases and select IR 0.4 explicitly; older cores
must not ignore the field. Keep unversioned IR constructor, old wire shapes and
source profiles fixed; raw-only selection first. No new nominal/provider profile
or actual host value is required: result has exactly the origin capability input
type, preserving named identities rather than their representation alone.

Only the direct designated child of a reconcile owner may declare this snapshot.
No root, ordinary creator, fault-handler use, ports, nested scopes or independently
created storage. Require its origin to be an exact non-human capability activity
declared directly in that owner and matched by its capturing entry wait; require
supported ordinary coverage of the origin and synchronous owner creator. Snapshot
cell is local, exact typed, uninitialized and readonly even at unvisited writers.
Keep ordinary visibility/provider/protection checks. Other unrelated declared uses
cannot borrow these cells; no arbitrary ancestor-input retention or shared values.

Extend the existing bounded fresh-local owned follow-up judgment, retaining the
old data-free and empty-map behavior and distinct ordinary/conditional sets. Check
snapshot target write access against empty pre-entry values before seeding it,
then initialize fresh locals, capture and check local wait/compute/decision/finish
flow. Preserve all-declaration body/read/write restrictions. Reuse one retained
ordinary proof chain and conservative source/owner/control/provider provenance;
zero inherited live values does not erase labels. Retain original request input
influences, including control/fault existence and policy dependencies. Compare all
publication/destination access and require strict conditional local invalidation;
no advisory promotion, recursive composed revalidation or cached current grants.

Snapshot means the one immutable value actually accepted for the original logical
request, not re-evaluation at closure/arrival/retry. Host premises must bind exact
definition/instance/owner/source occurrence, request/value digest and revisions,
logical effect/key/attempt correlation, current source/target authority, fresh
owned immutable storage, provenance and atomic accepted handoff. A later changed
request requires new work; it cannot replace the retained value or reset retries.
It cannot initialize ordinary parent values, settle an obligation, authenticate
an observation, continue cancelled ordinary work or resume the parent.

Expose immutable declared snapshot rows through static/owned conditional SDK
reports with exact origin/result/type relation and host premises, sharing retained
metadata and charging indexing, work, copies and rows cumulatively. Keep native
source CLI unchanged until explicit versioned authoring support; prior native
reports and package bytes stay identical. Bound all raw evidence and fail before
partial proof. Do not create a reference engine or claim actual owned allocation.

Test raw nullable/closed/version/role/hash/roundtrip boundaries, exact inherited
artifacts and nominal/provider identities, source ownership and actual capture
binding, ordinary/unvisited/human/unexplored/exceptional origin refusal, readonly
and creator/port/storage restrictions. Test retained read/copy/branch with fresh
local initialization, source/control/constant/branch/initializer protection,
empty pre-entry self/peer/ancestor access, strict invalidation, changed current
ancestor unavailability, alias/shared-template and cumulative work/copy bounds.
Use real SDK vectors plus limited independent Python schema/hash/finite checks;
explicit premises and remaining host requirements stay visible. Test promoted full
RP-01 privately, without adopting generated snapshots or changing committed bytes.

Run native/Wasm/all Python/final-head CI, separate completed-diff delegated review,
all unresolved threads/CodeRabbit summaries and signed expected-head merge. Update
progress with the exact next dependency: readable retained-request selection, then
permitted new work with current authority inside the surviving boundary and explicit
cancellation/closure cutoff/atomic handoff/all-settlement. Complete validator /
benchmarks, tool-managed general near-English and protected accessible visual
editing, actual host/browser/user/independent and all phase gates remain open.
Parent #46 draft/incomplete, all forty scenarios Partial; no Phase 2 or phase exit.
