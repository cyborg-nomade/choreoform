# Experimental source0.19 whole-process alternatives

These finite alternatives use the current [RP-01](../../benchmarks/rp01/README.md)
and [RP-03](../../benchmarks/rp03/README.md) resources unchanged. Paths above are
relative to this directory; the resources themselves remain in the benchmark
packages. No manifest, report, resource, receipt or guard is replaced here.

The native test-only `support/predicate_recipes.rs` transformation locates actual
source spans and verifies the complete normalized existing IR templates. It
reproduces these source and binding files exactly (binding JSON structurally).
It is a finite experiment, not a supported general exporter or managed editor.

RP-01 factors its complete payment completion/classifier condition with explicit
result/instruction inputs. RP-03 uses four explicit evidence/instruction/operation/
phase inputs, the complete thirteen- and fourteen-comparison balanced shapes, and
all fifty-five original cases. Explicit unwrap/payload dispatch remains in callers.
Twenty-three distinct nominal result types remain distinct. No work, storage,
occurrence, endpoint, authority or execution is shared by factoring a pure test.

See the [implementation and evidence](../0090-pure-predicates.md) and
[accepted contract](../../decisions/0090-pure-predicate-recipes.md). Current package
adoption requires a separate archive-first scope and is not performed here.
