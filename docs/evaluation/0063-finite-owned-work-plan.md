# Finite owned work and pure local inputs: frozen raw SDK plan

**Date:** 2026-11-10<br>
**Baseline:** `24d91c6f4b71e3aa6400250997301842d38420b0`, draft #46 after #77<br>
**Authority:** ADR-0018 / ADR-0062; conditional declarations, no actual host activation

Use a dedicated stacked implementation branch/PR and ADR-0063. Publish an explicit
exact core 0.11 on existing IR 0.4, requiring all ten inherited bases and uniform
selected aliases. Preserve all earlier core/source/wire/schema/artifact/hash/quota /
report meanings and committed benchmark bytes. Extend only explicit known-core
metadata/general-source/retry/capture/history/retention/continuation families;
unknown versions refuse. Raw SDK first; readable/native selection follows its own
explicit profile. No new wire relation has been demonstrated necessary.

Extend only the distinct finite owned continuation family, not ordinary/legacy /
old-flat coverage. Keep the ordinary invoke/repeat root with one actual external
source and its exact designated direct child; each intermediate body has exactly
one capability activity and its own exact designated direct child, ending in a
passive capturing leaf. Inspect all nodes/children, including unvisited declarations.
Preserve finite acyclic scope/control shape, source possible coverage at the root
and actual prior conditional coverage for nested source activities. All body reads /
writes stay local; no ordinary creators, P4/history reuse/faultInput, ports, human /
parallel work, foreign storage or arbitrary nesting is added.

Readonly original accepted request retention stays exact, uninitialized, readonly,
source/input-type/owner bound, with zero inherited live values and empty pre-entry
write access, fresh local initialization and no counterfeit seed. Allow the sole
activity's input to be any existing supported pure parameterless expression with
its actual capability input type and complete declared reads. Existing normal static
checks establish purity/type/read closure; conditional control/protection must check
all local input/policy/control dependencies at the use. Never seed a source/ancestor
result or unknown fact. A new child's retained request has its source activity's
actual input type, which may differ from its parent's incoming retained type.

Preserve one attempt, no timeout/retry clock and an explicit matching supported
general fault source for every new activity. Support exact matched read-only,
compensatable and irreversible effect classes; require stable-key provider/effect
metadata for non-read-only work. An optional compensates link may name only this
level's immediate original source activity, never itself/another ancestor or an
unrelated declaration. Own effect class and compensation purpose remain independent.
A non-read-only activity OR any explicit compensator (even read-only class) requires
capturing-first entry at that original source's unique actual-use effect-policy,
same-body timerless capture wait. Require its target local, uninitialized and written
only by that wait. Preserve the source subscription and actual transitive ownership;
accepted capture does not mean a local finish settled all obligations. Uncompensated
read-only inquiry may retain core-0.10 pre-capture entry; all availability/recipient /
invalidation barriers remain. Broader preterminal commands/possibly-completed
compensation, non-stable-key commands, multiple attempts/timers/extra work and
richer P4/ownership contexts stay explicit later work.

Reuse bounded borrowed wait/writer indexes and shared immutable templates. Track the
actual sole activity as the next level's source independently of the old query
getter. Keep query meaning uncompensated read-only inquiry; commands/compensators
must not be mislabeled as queries. Add an immutable optional new-core work relation
naming activity, capability, input expression, closed effect class and optional
compensation source, with mandatory host requirements. Old core rows/getters remain
fixed; old native outputs omit the new relation until explicit readable integration.
Tie work to existing same-revision owner/source/request/closure/child relations.
Reserve new copies/index/template/final publication cumulatively, return no partial
proof on exhaustion and never rerun public admission per body or for serialization.

Reuse one conditional control/protection chain and exact prior source contexts.
Enforce complete original input/request/policy/source/fault/control/provider /
creator-owner provenance as labels, not values or cached grants. Require the actual
capability recipient in every consumed/control/access/input envelope, including
no-result activities and constructed/constant inputs; do not restrict checks to
result writes. Check fresh initializers, local reads/writes/branches/complete policy
closure, strict invalidation and all source dependencies. Keep ordinary-only
history-entry and nearest/active fault-selection barriers. New work's general
source/possible fault names do not become ordinary coverage or actual faults.

Actual host gates remain mandatory: accepted occurrence-bound P6 registration and
atomic handoff before entry; fresh current data/work/capability/management authority,
open noncancelled receiver and respected source cutoff/disposal; exact definition /
instance/owner/source/request/input/value revision/digest/logical effect/key/attempt;
fresh immutable occurrence-owned accepted input storage and authenticated complete
provenance. New business work/compensation gets a NEW logical effect/key; only
technical attempts keep identity. Supported stable-key implementation and atomic
request/key recording are not supplied by metadata. Commands/compensators require
actual accepted correlated source capture before dispatch and appropriate business
invariant/consequential/irreversible conflict acceptance. Explicit compensation also
requires a currently eligible confirmed or possibly completed prior effect and exact
accepted prior occurrence correlation; a declaration/tag/class alone never proves
eligibility or success. Definitive no-effect/contradictory history must be handled
according to actual evidence, not called a rollback. Do not grant execution or invent
receipts. Failed receiver acceptance leaves the old owner accountable; preserve all
actually activated transitive effects/subscriptions/children through handoff until
accepted settlement. No original-key retry substitution, parent resumption, source
settlement, cancellation clearing, terminal reopening or liveness is inferred.

Test every supported class/link combination with matched metadata, capturing-first
and read-only pre-capture compatibility, constructors/identity wrappers/constants /
typed capture-derived inputs and differently typed child seeds through complete
SDK stages. Include mixed chains (command -> read-only child and read-only ->
command child), reused creators/shared immutable declarations, all exact core bases /
uniform wire selection, unchanged older refusals/row meanings. Test early commands /
read-only compensators, unstable-key commands, wrong/nonactivity/self/ancestor
compensation links, missing/mismatched general source, retry/timer/unsupported work,
wrong/missing/duplicate/unreachable/nonlocal/initialized/multiply-written source
waits/captures, early capture reads, missing input reads/type mismatch, no-result /
constant/constructed/control/initializer recipient leaks, empty seed access,
strict invalidation and unvisited sources/extra work. Exercise cumulative index /
context/template/copy/final publication exhaustion without partial proof. Add shared
isolated raw vectors consumed by actual SDK and a limited independent Python model
with exact new/base hashes/compatibility/licensing/CI checks; never call the model
complete validation, actual provider evidence or independent human review.

Run required native/Wasm/all Python checks and final-head CI, separately review the
completed diff for correctness/security/performance/scope/evidence, audit all
unresolved threads/summary findings and merge signed at expected head. Record skipped
bot review as no evidence. Update progress/draft #46 with next separate readable /
native profile and remaining broader command/compensation/P4/ownership work.
Forty scenarios remain Partial, G1–G4 conditional; complete validator/benchmarks /
general tool-managed near-English/protected accessible visual editing and actual
host/browser/user/independent/phase evidence remain open. No Phase 2. Freeze/sign a
refinement before any demonstrated scope/serialized-contract change; no per-item
owner permission is needed under standing delegation.
