# Readable finite continuation and native disclosure evidence

**Date:** 2026-11-10<br>
**Baseline:** `e38f7caf674416a00a718f4ca77940883e086b58`, draft #46 after #72<br>
**Authority:** ADR-0018 / [ADR-0058](../decisions/0058-readonly-continuation-authoring.md)<br>
**Frozen plan:** `7e7dfb3`, [plan](0058-readonly-continuation-authoring-plan.md)

Source 0.12 / companion 0.11 explicitly selects existing core 0.9/IR 0.4 and all
eight inherited bases. Grammar productions are identical to source 0.11; existing
nested request/capture/retention/closure sentences express the finite family. No
new wire field, value, event, receipt, resource kind or permission syntax is added.
Older profiles/contracts/schemas/artifacts/hashes/quotas/report meanings stay fixed.
Normal roles, visibility, complete metadata reads, original UTF-8 private clause
spans and public span inventories remain intact. Libraries require exact artifacts;
CLI embeds only known core/semantics bytes, with actual metadata still explicit.

Every native checking/advisory view preserves inherited static declarations.
The six views from concurrency onward expose creator/owner relations, one shared
conditional scope catalogue and separate conditional nodes/scopes/transfers /
access/provenance/invalidation/gates/remaining premises. Scope rows identify root
owner, immediate owner, incoming closure, exact source/request, conditional-source
status, query and child. Gate rows name management actors and mandatory live host
requirements, never accepted transitions. Exact input type is identified by the
validated same-revision static request relation, avoiding repeated type schemas.
Final reconciliation names continuationScopes separately from retainedRequestScopes
and legacy coverage; conditional nodes remain legacy-uncovered. Earlier views
disclose declarations without promoting coverage. Empty fields stay omitted.

Native disclosure reuses the already-composed immutable proof. It reserves inherited
output before new bounded rows, deduplicates scope relations for reused creators,
and keeps the final whole 1 MiB writer bound before stdout. Exhaustion returns
report-budget without partial output; revision mismatch refuses. One native unit
group checks a genuine reused-creator SDK report (two creators, two shared scope
rows, seven gates), inherited-output exhaustion without mutating the caller's
partial value, and revision mismatch. This is static serialization evidence only.

Three Rust frontend groups check:

- exact equality of readable and raw reference scope/node/flow/expression tables,
  all eleven SDK stages, typed capture/request declarations, distinct conditional
  proof/gates and preserved ordinary/legacy/old-flat boundaries;
- format/reparse, coordinated Unicode scope aliases, qualified origins and exact
  original UTF-8 request-clause diagnostic spans;
- every required semantics/core artifact, explicit source/companion pairing and
  older source 0.11 refusing nested retention under its unchanged core.

The small readable fixture is 6,588 UTF-8 source bytes / 1,142 tokens and lowers to
11,594 output bytes including newline. It reuses the committed raw synthetic
metadata bytes. Normal source capabilities generate their own provider-policy
aliases; the raw fixture's unused shared provider policy is retained explicitly.
Two excess descendant invalidations on the ordinary result, left over from its
earlier ordinary capture probe, are omitted: normal source lexical references
cannot express them and the complete SDK proof requires neither. No accepted
benchmark metadata or visibility rule is broadened to obtain a passing query.

Six independent Python groups check all eleven native views, schema/grammar/pair
selection, independent package framing, format/Unicode identity, actual raw refusal
stages and clause locations, old/default omissions and old flat proof under the
new explicit profile, valid combined report exhaustion, licensing and CI. They do
not implement a general semantic validator or substitute for independent people.

The combined stress package adds 130 valid, unvisited typed-history handler entries
under a sibling owner, retaining the real two-level conditional proof and seven
gates in its small form. Fresh synthetic descriptor IDs are long but remain within
all existing limits. Its 90,320 source bytes / 14,069 tokens, 617,803 companion bytes
with ordinary JSON spacing, and 646,644 lowered output bytes including newline fit
the existing bounds. The small one-entry variant passes all eleven native views;
the 130-entry variant lowers successfully then every checking/advisory view refuses
report-budget with empty stdout. No event values, actual observations or host
receipts are generated; these are real native judgments on static declarations.

Local validation passed: 482 Rust tests plus six compile-fail doctests, native and
all five Wasm Clippy checks, release Wasm portability/frontend builds, native
portability report and all 55 Python workflow commands, including deterministic
benchmark regeneration. The final new Python group passed after correcting a
variable-name error in its added old-flat compatibility check. Completed-diff
delegated self-review covered correctness/security/performance/scope/evidence,
explicit pins/pairs/roles, immutable proof reuse and separate coverage, row sharing,
cumulative/final bounds, compatibility and licensing. No actionable issue remains.
This is agent self-review under ADR-0018, not independent/human or personal owner
review. Final-head CI/all comment audit and signed expected-head merge remain required before integration. Logs use
`/private/tmp/readonly-authoring-{workspace,verify,python}.log`. Compilation is not
browser execution. Committed RP-01 remains source 0.7/core 0.4/IR 0.1 and its
existing source/report/guard/package bytes stay fixed. No scenario is promoted.

cutoff, occurrence/request/input/value revision/digest/effect/key/attempt correlation,

settled. Finite shape is no liveness or eventual-settlement proof.
