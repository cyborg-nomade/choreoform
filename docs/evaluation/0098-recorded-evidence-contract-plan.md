Freeze/sign `codex/recorded-evidence-contract` before its comparison/contract.
Preparatory design may precede dependency integration; production implementation
is a later dedicated scope after this exact publication has been signed/reviewed /

Publish one bounded **representation and admission** contract for externally
recorded evidence/history, driven by RP08 R23–R26 and all four scenario/privacy /
closure contexts in [the full critique](0097-rp08-coverage-design.md). Keep immutable
source claims, provenance, known time/causal facts, current trusted acceptance,
process decisions/effects and executable history distinct. This is not a generic
runtime importer, replay engine, authentication system or Phase2 implementation.
It cannot make a nonexistent complete RP08 package executable or satisfy all gaps.

Read accepted immutable history/identity/correlation/clock/policy contracts, current
provider/fault/terminal/capture/retention/owned-work records, native transport /
JCS/value/resource checking interfaces, the complete RP08 brief and authoring /
artifact/session boundaries. Compare at least: a closed inert evidence envelope
with explicit supported payload/profile contracts; opaque record storage alone;
and a general executable runtime-history event stream. Choose by requirements,
stable identity/provenance, precise refusal/stages, privacy/access, partial-order
meaning, bounded implementation, native/Wasm portability and future faithful UI.
Do not choose a convenient subset and call it the complete historical case.

Define and publish exactly, before new production code:

- Artifact/version/namespace and source/event/record/delivery identity, exact
  immutable payload and profile/resource bindings, integrity/canonical/raw-byte
  distinctions, provenance/claimed facts and explicit incident/occurrence/revision
  correlation. A source-like name/hash/nominal value is no authenticated source,
  physical alias or accepted original snapshot; do not infer IDs from order/labels.
- Equal duplicates versus conflicting reuse, revisions/late/contradictory evidence,
  retained originals and refusal/quarantine boundaries. Define what gets retained
  outside a refused artifact; no partial-success/truncated model or silent overwrite.
- Known causal/order links and explicit external-reference/unknown boundaries;
  acyclicity/scope/reference validity, unrelated/tied/unknown timestamps and clock
  domains/bases. Stable storage/topological display order is not a discovered total
  order. Never compare incompatible clocks or invent causal relations from time/ID.
- Current import/evidence acceptance versus historic occurrence/decision authority,
  assignment/effect state and terminal history. Unsupported profiles/semantic
  fields refuse admission; ordinary payload values/annotations cannot issue current
  grants, accepted decisions, engine transitions, automatic dispatch or replay.
- Exact trusted integration assumptions for artifact read/inspect/export before
  disclosure, separately from data protection/process actor labels/untrusted JSON.
  Define privacy/authenticity/stale binding and complete-versus-audience boundaries;
  no hidden-content inference or redacted complete-artifact reconstruction. Do not
  claim production identity/DLP/host enforcement from a document, report or digest.
- Closed schemas/grammar as applicable, exact SDK/CLI/bridge/report/error interfaces
  and supported profile selection for later implementation. Keep report stages
  non-executable and claims falsifiable. Caller/host prerequisites must be explicit,
  not a self-authorizing Boolean in input. No arbitrary path/URI fetching/discovery,
  executable HTML/script or ambient network/clock/random/thread/provider capability.
- Inclusive raw/decoded/container/item/string/record/link/resource/work/output bounds
  and preflight before copy/growth/expansion. No relaxed existing quota. Avoid all-
  pairs/transitive-output amplification; refused diagnostics use fixed private codes /
  locations and never echo arbitrary evidence/source/principal/payload/paths.

Preserve Rust/one semantic model, source19/companion18/C12/IR4 and raw-SDK-only C13
