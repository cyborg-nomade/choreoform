# Finite owned work and pure local input evidence

**Date:** 2026-11-10<br>
**Baseline:** `24d91c6f4b71e3aa6400250997301842d38420b0`, draft #46 after #77<br>
**Authority:** ADR-0018 / [ADR-0063](../decisions/0063-finite-owned-work.md)<br>
**Frozen plan:** `cd9904b`, [plan](0063-finite-owned-work-plan.md)

Exact core 0.11 selects existing IR 0.4 and every one of ten inherited exact bases.
Artifact: `sha256:246bf3835eef25f8adf76bce39e6b887715e098761e675f821bf745a8111d29e`.
All prior source/core/wire/schema/artifact/hash/report meanings and quotas remain
fixed, including source 0.13/core 0.10 selection and committed RP-01 bytes. No wire
field is added; readable/native work disclosure follows separately.

A dedicated small work module has a closed effect-class enum and immutable private
work fields/getters. Normal definition checks already establish provider/type/pure
input/complete-read/source compatibility. The new conditional work check imposes
one attempt/no timeout/matching general source, non-read-only stable-key and immediate
source compensation. Only commands/explicit compensators use capturing-first entry
with the actual-use wait and exclusive uninitialized capture target. Existing
read-only pre-capture entry and every local availability/access/control/protection /
actual recipient/invalidation barrier remain. Input construction introduces no extra
live seed or inherited grant; child input types stay exact per actual source activity.

The proof tracks its sole actual activity independently of the query getter, so a
command with query=None still becomes the next level's exact conditional source.
New-core intermediate scopes expose optional work; queries mean uncompensated
read-only inquiry, and passive leaves/old-core rows omit work. Immutable templates
are shared across reused creators, not values/storage/permissions. Exact profile
selection is cached once in the candidate index to avoid repeated alias scans per
activity. All new work copies consume cumulative stage budgets before publication.
No public admission is rerun for individual bodies or report serialization.

Fifteen new complete-SDK groups cover:

- original/new class and independent compensation links, distinct work versus query,
  actual site/capability/input/class/link and live host requirements, seven gates;
- only uncompensated read-only early entry; refused early commands/compensators,
  unstable-key commands, missing general source and self/nonactivity/ancestor links;
- exact constant/identity/capture-derived inputs, genuinely different next-child seed
  types, early captured-read refusal and unchanged normal type/complete-read failures;
- mixed command -> early read-only inquiry and read-only -> command chains, exact
  prior conditional source contexts, passive third leaf and ten declared gates;
- actual-use wait binding, local uninitialized/singly written capture target,
  compatible exact bases/aliases and old-core effect refusals;
- real supported clock descriptors with otherwise statically valid timeout and retry
  policies, then the actual owned-continuation-work-policy refusal;
- empty self/peer/ancestor seed access, strict invalidation, retained/control recipient
  enforcement for constant input and a no-result command, plus reused creator sharing;
- all 21 shared isolated cases through the actual composed SDK.

The no-result command probe passes before adding a narrower local flag/branch, then
refuses owned-continuation-recipient without an input read or result publication.
A separate retained-label probe initially refused control-information-flow at its
preceding capture publication, correctly: the capture destination was wider than
the narrowed retained label. Restricting that destination consistently lets the
probe reach the intended actual capability recipient check. No provider metadata
was broadened to obtain a pass. A test borrow initially outlived its temporary
scope view; retaining the immutable scope views fixes that test setup.

One new private budget group shares the existing test harness with the old early-
entry path: bounded template/work copies, shared Arc identity across creators and
aggregate final-row exhaustion return budget with no partial roots/report. The
shared corpus explicitly describes setup selectors for prevalidated matching
synthetic metadata; they are not serialized IR fields, a general validator or actual
provider facts. Five limited Python groups check independently derived isolated
premises, exact new/all-ten base hashes, unchanged IR 0.4 schema representation,
old source/native selection/omissions, licensing and required CI. These do not
substitute for independent people, actual values, grants or accepted host events.
