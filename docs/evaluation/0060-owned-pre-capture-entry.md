same-body timerless capturing wait. A second borrowed index requires that wait's

public admission is rerun per body. Existing capturing-entry paths skip this new
relation check. A distinct optional immutable entry/capture relation is available
only on the new intermediate conditional mode, with explicit live host premises.

initializer could make a terminal capture value available before the wait; an
ordinary compute could do the same. The initializer regression failed against the
initial implementation. Both cases now refuse at retained-request-source-result,
before conditional availability. The new artifact was finalized only after adding
the local/uninitialized/sole-writer requirement. No published contract was rewritten.
