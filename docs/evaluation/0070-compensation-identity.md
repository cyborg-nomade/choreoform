## Scope and implementation

Exact [core 0.12](../dialects/core-compensation-identity-v0.12.md) changes only P1
`compensates` identity visibility on existing IR 0.4. It requires eleven exact
inherited cores, uniform selected aliases and the known exact pin. Earlier contract /
source/schema/artifact/hash/report meanings and all budgets remain fixed. The new
core joins the inherited metadata/source/capture/retention/continuation/finite-work
families; unknown/wrong selections cannot quietly skip those judgments.

Static Check caches new-core selection after contract/wire verification. In the
single `compensates` slot, it charges shared work and borrows the exact same-definition
node, requiring capability activity kind/mode. All other references still use the
existing lexical resolution; no global resolver, dynamic occurrence selector,
ordinary private value/outcome/control/policy access or runtime authority is added.
Old profiles still check lexical visibility before target kind. Four existing
private static tests initialize the new flag false, retaining their old costs.
