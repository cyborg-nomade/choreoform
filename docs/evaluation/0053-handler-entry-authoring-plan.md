Use this dedicated stacked dependency PR and ADR-0053. Publish explicit source
0.10.0 / companion 0.9.0 selecting core 0.7 / IR 0.3 and all six inherited bases.
Keep every earlier grammar/schema/core/wire/hash/report domain fixed. Copy source

`Receive fault history from "Payment history" and record in "Fault history".`

such clause. Resolve normally visible provider-fault-history resource then local
data cell; no private endpoint exception, hidden fault fact or source-name inference.
Names stay readable and existing type/protection/invalidation syntax remains explicit.
General resource/identity editing tools and complete English-expression usability
remain separate visible roadmap work; manual IDs/JSON are not the authoring goal.

exact SDK metadata readers for descriptor/profile/source/provider/fixed nominal
bytes; validate missing/corrupt/wrong-kind/unsupported resources and unused declared
resources normally. CLI embeds known semantics/core bytes only; actual history /
source/profile/type resources remain explicit. Libraries require every inherited
artifact. Lower every scope's required nullable faultInput on the new wire, deriving
exact history pin/local result and normal semantic span mapping to the clause.
No initializer/writer or value is invented. Preserve general-source/retry/capture,
finite read/closure, actual-use endpoints and every prior semantic refusal.

Known whole programs retain 16,384 tokens / 1,000,000 recognizer visits, existing
100,000 lowering/dependency allowance and 1 MiB transport/output bounds. Add only
closed known profile checks; no lexical version ordering or implicit migration.
Unknown 1.0/fragment legacy quotas stay fixed. Version the package framing domain
as source 0.10; formatting/reparse/coordinated aliases preserve identities/IR within
that profile, while explicit promotion changes version/core/wire semantic hashes.

Integrate typed proof into exceptional-availability and later pipeline stages only
when explicit non-null scope bindings exist. Reuse one check_fault_entries/origin /
prior-stage chain, not a second admission for output. Retain legacy ancestor-input
handler coverage only for unbound handlers. Expose typed history proof separately;
never add its bodies/assumptions to ordinary or legacy checked sets. Legacy uncovered
sets may still contain those nodes, with the separate conditional sets explained.
Carry the typed proof through reconciliation/link stages without turning it into
P6 value retention, current grants, resumption or owned continuation.

Share immutable FaultReport evidence between retained origin/entry and exceptional
views using an internal Arc rather than duplicating reports or rerunning checks.

Record the small fixed report-sharing allocation tradeoff honestly; no live values,
current permissions or occurrences are cached. Update the previous raw-only test
that expected exceptional refusal: versioned typed definitions now return separate
conditional proof, while ordinary/legacy coverage remains unchanged.

All ten checking views plus advisory invalidation requirements disclose nonempty
static declaredFaultEntries from retained static rows. Use one catalogue per exact
history descriptor, with exact source/profile/provider/fixed nominal identity,
separate from actual history values. Reuse immutable metadata and avoid repeated
full schema/provider/emission copies. At exceptional and later stages additionally
disclose conditionalFaultEntries: covered/uncovered entry scopes, conditional body

site/selection/full-context relations and mandatory host premises. Keep declared
unvisited/unexplored entries and conditional proof distinct from activation.

writer bound before stdout, including inherited capture/general source/retry/
historical/isolated/owned-local fields. Omit empty fields on older reports. Refuse
report-budget before stdout, never truncate, silently drop declarations or rerun
admission. Stress accepted bounded sources with long descriptor IDs and many
unexplored handler aliases under one unused owner; this avoids creating artificial
active routing cycles merely to test output size. All actual/metadata contexts must
still validate. No generated observations or host runs are substituted for evidence.
