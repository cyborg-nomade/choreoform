**Date:** 2026-11-11<br>

**Dependency:** #93 final-head CI, full comment audit and signed parent merge before design/probes<br>
**Authority:** ADR-0018 / ADR-0078; inactive contract/schema/examples/pure prototype/tests/docs

Freeze/sign dedicated `codex/external-interference-contract-design` before design /
probes. Preserve all existing production Rust/resource/concurrency/source/diagnostic /
profile/core/IR/policy/schema/quota meanings, every accepted normative artifact/pin,
Manifest and all current/historical RP-01/RP-03/guard/corpus/generator/report bytes.
Do not activate new semantics in an existing core/profile or claim the current
checker accepts a new descriptor. No benchmark relabeling, serialization or unsafe
independence flag. New draft artifacts/examples remain explicitly inactive.

Settle a concrete finite contract and its trust/proof boundary against ADR-0078's
requirements, including a comparison of a separately pinned provider-bound resource
versus a provider-contract version change. Favor the supplementary resource only
if exact provider/profile/type/version/authority/metadata consequences are sound.
Record the critique/options before fixing the selected design in ADR-0079 under
delegation. Determine exact closed shape, identity/digest/profile/version rules,
unknown/opaque behavior, exhaustive reads/observations and writes/effects, canonical
namespace/alias semantics and bounded typed selectors from immutable accepted
requests. No arbitrary host code/current-cell lookup or merely different IDs.

Evaluate the distinction between statically proved independence and a conditional
runtime conflict-admission/enforcement requirement; never present the latter as
already executed or as a free safety flag. Actual canonical physical bindings,
provider/normalizer/host support and truthful/exhaustive claims remain external
requirements. Unknown/unregistered/ambiguous/missing/optional/unsupported inputs
must fail closed or remain explicitly unproved. Human/unsupported observations
stay opaque. Preserve original protection labels and local storage/lifetime gates.

Specify revision/cohort/actual occurrence/logical effect/technical retry/capture /
compensation correlation. A disequality within one input version does not prove
independence across revised inputs or earlier unresolved work. Resolve uncertainty,
cutoffs, lease/ownership/settlement responsibilities and atomic handoff requirements
at the contract level; a domain assertion cannot dispose of an obligation or grant
current actor/receiver authority. Do not claim a real monitor, registration,
provider approval, accepted observation, live value or host execution.

Implement only an explicitly pure inactive prototype/oracle and closed draft schema /
examples sufficient to exercise the selected finite rules. Label concrete test
values/model transitions as synthetic mathematical examples, never process/host /
user observations. Cover supported and refused selectors/types, same/conflicting /
unknown/aliased regions, input revision and original-versus-current request cases,
readonly/opaque/class compatibility and bounded work/output as relevant. Use real
pinned provider/type bytes for references where useful; do not overwrite any old
resource. An unused draft resource is not evidence of current-core acceptance.

The design must identify a reviewable next implementation/version/pinning/source /
raw/evidence plan and honest remaining limitations before production integration.
Keep native/Wasm/Rust portability and near-English managed bindings as explicit
integration criteria without exposing technical hashes in author-facing flows.
New syntax/schema/core/resource-reader/concurrency admission requires that separate
signed plan, including any new normative artifact byte hashes, not silent adoption.

portability/Python checks plus meaningful draft/prototype tests. Separate completed-
