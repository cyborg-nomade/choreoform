# ADR-0063: Check finite owned work and pure local input construction

**Status:** Accepted under Project Owner delegation; effective on parent/main integration<br>
**Date:** 2026-11-10<br>
**Decider:** Codex under ADR-0018 owner delegation

## Context

ADR-0062's genuine SDK/frontend audit separates own effect class, compensation link
and input construction. Existing IR 0.4 represents the bounded cases; old core 0.10
correctly refuses them. The signed [raw plan](../evaluation/0063-finite-owned-work-plan.md),
`cd9904b`, precedes production changes. All earlier profiles/artifacts stay fixed.

## Decision

Publish [exact core 0.11](../dialects/core-owned-work-v0.11.md) on existing IR 0.4,
requiring all ten inherited bases and uniform selected aliases. Extend only the
explicit known-core families. Keep the distinct finite one-capability/direct-child
ownership chain, readonly exact original request seeds after empty pre-entry access,
all-declaration/source/context/local-storage checks and passive capturing leaf.

Allow normal supported pure parameterless capability input expressions over available
local data, with exact actual input type/complete reads and the existing conditional
availability/protection/actual recipient/invalidation proof. Each child retains its
own source's actual accepted request type, possibly different from its parent's seed.
No source/ancestor result or unknown fact is seeded or fabricated.

Support matched read-only/compensatable/irreversible work; require stable-key for
non-read-only providers/effects, one attempt, no timeout/retry clock and an explicit
matching supported general source. Optional compensates names only the immediate
original source. Non-read-only activities and every explicit compensator, including
read-only class, enter at the original source's actual-use same-body timerless
capture, with local uninitialized exclusively written target. Only uncompensated
read-only inquiry keeps core 0.10 pre-capture entry. Commands before capture,
non-stable-key commands, retries/timers/extra work and general P4/ownership stay out.

Expose an immutable optional work relation for this new core, naming site/capability /
input expression/closed effect class/optional compensation with mandatory live host
requirements. Keep query getter meaning uncompensated read-only inquiry; commands
and compensators are not mislabeled as queries. Track the actual activity, not that
query getter, as the next conditional source. Reuse bounded borrowed indexes/shared
immutable templates and one conditional control/protection chain; cache profile
selection once per index. Preserve cumulative copies/proof/publication bounds,
ordinary/legacy/old-flat sets and ordinary-only history-entry barriers. Raw SDK only;
readable/native selection follows a separate explicit profile, with old outputs fixed.

## Consequences and live boundary

New business work/compensation gets a NEW logical effect/key; only technical attempts
retain identity. Metadata proves no provider implementation, atomic accepted request /
key record, current grant or actual effect. Actual accepted P6 registration/atomic
handoff before entry, current authority/open receiver/cutoff/disposal, exact occurrence /
input/value revisions/digest/effect/key/attempt, immutable storage/full authenticated
provenance and appropriate business/consequential/irreversible conflict acceptance
remain mandatory host gates. Commands/compensators require actual accepted correlated
source capture before dispatch. Explicit compensation also needs an actually eligible
prior effect and accepted occurrence correlation; a tag/class/declaration proves no
eligibility, rollback or restoration. Failed handoff leaves the old owner accountable;
all actually activated transitive effects/subscriptions/children remain owned until
accepted settlement. No parent resumption, original settlement or liveness follows.

Fifteen full-SDK groups, one private cumulative-budget group and 21 shared finite
cases/five limited Python groups cover supported work and inherited barriers. The
case setup explicitly promises matching synthetic metadata; selectors are not wire
fields/general validation or actual observations. See the
[evidence](../evaluation/0063-finite-owned-work.md). Parent #46 remains draft, all
forty scenarios Partial and G1–G4 conditional. Broader preterminal/possibly-completed
compensation, complete validator/benchmarks/general near-English/protected accessible
visual and actual host/browser/user/independent/phase evidence stay open. No Phase 2.
