## Decision

Retain current concurrency refusal. C13 explicit metadata selection is not the
missing generic proof. Before extending acceptance, require a separately signed
supported canonicalization/provenance/admissibility design: physical alias and
non-alias meaning, actual original input snapshot correlation and every admissible
overlapping revised/surviving occurrence must be accounted for. Exact P3/P4/P6 /
invalidation/ownership/closure constraints remain mandatory; type-valid value
permutations neither prove nor bypass them. Do not manufacture a descriptor,
relabel provider effects or serialize the representative parallel graph to pass.
Runtime exclusion is not selected by this audit and needs its own contract and
actual implementation/evidence if ever proposed.

Proceed next with independent Phase 1 **near-English factoring critique/evaluation**.
The required accessible language deliverable remains open, and current RP-03's
576759 bytes/84051 tokens show substantial repeated service/protection/receipt
boilerplate. Compare concrete controlled-English reuse options, identity/typing /
protection/compensation/instance boundaries, managed resources and full RP-01/03/08
source/raw/visual/user evidence requirements before changing syntax. Keep Candidate
A's provisional direction and the goal of broad non-programmer accessibility.
No automatic parser quota, hidden claim widening or unimplemented example counts
as authoring or representative-user evidence. Keep this work in Phase 1.
