Rust/C12 and all13 exact premises remain explicit; raw-SDK C13 stays outside selection.
No current wire/provider/source/IR/authoring/native/view API or quota is changed.

Preserve original literal bytes and distinct documentary event/witness/delivery
claims. Equal immutable cores may repeat without being new accepted events;
conflicting reuse refuses wholly. Core digests bind the complete resolved reported
clock basis, not its local ID: renaming that ID preserves the digest, changed
origin does not. Clock coordinates/source identities remain claims. The resolved
projection is no timezone conversion, source normalization or actual clock read.

Asserted order/cause is checked as a bounded graph over explicit identity classes,
including aliases and unknown boundaries; no timestamp/map/ID-derived edge or
purported unique chronology. Unknown content is not fetched/reconstructed. Original
text, type values, source-like labels, context/permission claims and the fixed inert
report cannot grant access, accept historic decisions or mutate terminal history.
Complete artifact read/inspect/export must be authorized by trusted integration
outside inputs; no production identity/DLP or audience-redaction claim.

The comparison rejects opaque storage as the entire answer and a generic executable
runtime stream as this deliverable. The chosen model retains inspectable original,
typed documentary and asserted-link meaning without inventing runtime state. Its
limits are explicit: only supported UTF-8/typed claims, no cross-artifact acceptance /
merge, no hidden model reconstruction, no actual source/normalizer/correlation /
authority/settlement proof. A standalone schema is not full type/pin/graph admission.
