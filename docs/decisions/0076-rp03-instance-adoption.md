**Status:** Accepted under Project Owner delegation; effective on parent/main integration<br>
**Date:** 2026-11-11<br>
**Decider:** Codex under ADR-0018 owner delegation

## Context

ADR-0075's complete two-caller effectful proof supports caller-local construction
under existing contracts. Signed [plan](../evaluation/0076-rp03-instance-adoption-plan.md)

## Decision

Adopt this deterministic synthetic checkpoint with all 26 invoke and seven split
child relationships valid. Twenty-five service instances represent 23 operations;
normal/surviving release A/B have distinct local definition identities. Preserve
typed business inputs, receipt/guard predicates/cases/types/launch bytes and exact
prior archives. Explicitly add only the two necessary logical capability recipients
to fictional provider/clock protection claims and repin exact source descriptors.
These are new synthetic claims, never real consent/eligibility/authority.

Keep source0.16/companion0.15/C12/IR0.4 and all production contracts/quotas unchanged.
Local requests and the original-order input explicitly invalidate their constructed
dependent work/decisions. Retain the genuine full strict/advisory refusal
`invalidation-context-unproved` at capture_activity. Select a separately signed
inherited-context provenance audit before changing that boundary. No influence is
dropped and no private sibling invalidation/read is invented to force acceptance.
