# Captured synthetic baseline for raw selection controls

`parallel-effects.ir.json` is actual native `lower` output for the complete C12
source/resource package produced by `proofs.parallel_effects.package` with two
compensatable integer providers. The Python oracle regenerates and compares its
exact bytes using the pinned native CLI. It is a fictional declaration, not an
execution, provider promise, accepted request, event or host observation.

Rust tests derive explicit C13 variants in memory, with fresh supplied descriptor
metadata. They test semantic selection/identity and preserve the actual effectful
concurrency refusal. A separate test derives a whole RP-03 raw variant from the
unchanged benchmark/resource files; it never rewrites the benchmark or claims
truth of synthetic exhaustive/canonical authority declarations.
